Install It // Pick Your Email App

Start from scratch

Create a brand-new signature // don't paste this into an existing one. Pasting into an old signature carries over its leftover fonts and spacing. Delete any signature you already have first, then add a new one and paste into that.

Outlook (Desktop / Web Browser)

  1. File > Account Info > Signatures > + Add signature (button)
  2. Click into the signature box
  3. Paste (Ctrl/Cmd+V)
  4. Add a signature name
  5. Check box for > Set default for new messages (optional)
  6. Check box for > Set default for replies and forwards (optional)
  7. Save

Outlook (Mobile App)

  1. Tap your profile icon next to "Inbox" (top left)
  2. Tap Settings "gear icon" (bottom left)
  3. Tap Signature
  4. Tap in the signature box (delete any existing text)
  5. Long press in the signature box to paste
    If on an Android device, do not use the built-in "clipboard" feature above the keyboard.
  6. Tap the check mark (top right) to save
