02 // Live preview

Updates as you type

Click "Copy signature" first, then follow the steps below. The signature pastes in fully formatted, so there's nothing to redesign.

Paste with Ctrl/Cmd+V. Don't right-click and paste: that can break the formatting.

Locked in every signature

  • The MOC box logo, the divider rule and the type sizes stay fixed, so every signature in the company matches.
  • Black and white only, per the MOC Brand Guidelines.
  • The website line (mocproducts.com) is fixed and not editable here.
  • The signature sits on a fixed white card with the boxed MOC logo, so it stays readable in dark mode in any email app.

03 // Install it

Pick your email app

Start from scratch

Create a brand-new signature // don't paste this into an existing one. An old signature carries over its leftover fonts and spacing. Delete any signature you already have, add a new one, and paste into that.

Outlook // Desktop and web

  1. File > Account Info > Signatures > + Add signature
  2. Click into the signature box
  3. Paste (Ctrl/Cmd+V)
  4. Add a signature name
  5. Tick "Set default for new messages" (optional)
  6. Tick "Set default for replies and forwards" (optional)
  7. Save

Outlook // Mobile app

  1. Tap your profile icon next to "Inbox" (top left)
  2. Tap Settings, the gear icon (bottom left)
  3. Tap Signature
  4. Tap in the signature box and delete any existing text
  5. Long press in the signature box to pasteAndroid: don't use the clipboard bar above the keyboard.
  6. Tap the check mark (top right) to save
